# Inducciones UNIMINUTO

Páginas HTML estáticas publicadas con GitHub Pages.

| Página | Archivo |
| --- | --- |
| Estrategias para Saber Pro | [`saber-pro.html`](saber-pro.html) |
| El uso de la coma | [`uso-de-la-coma.html`](uso-de-la-coma.html) |

`index.html` enlaza ambas páginas.

## Publicación

En **Settings → Pages**, elegir *Deploy from a branch*, rama `main` (o la rama por defecto) y carpeta `/ (root)`.
Las URL quedan así:

- `https://camiloayalam.github.io/inducciones-uniminuto/`
- `https://camiloayalam.github.io/inducciones-uniminuto/saber-pro.html`
- `https://camiloayalam.github.io/inducciones-uniminuto/uso-de-la-coma.html`
